# 🍕 PizzaHub — Frontend Client (Next.js 16 App Router)

Artisanal pizza ordering frontend interface featuring Next.js 16 with Turbopack, Tailwind CSS, Framer Motion animations, Dark/Light mode theme switching, and role-based dashboard navigation.

## ✨ Features
- **Public Routes**: Home page with banner, featured menu items, pizza categories, why choose us, how it works, and testimonials.
- **Browse Menu**: Multi-facet search, category pills, city location filters, and price/rating sorting.
- **Item Details**: Photo gallery, pizza ingredients, reviews with star ratings, and order form modal.
- **Role Dashboards**:
  - **Customer**: Order history, live status timeline, order cancellation, and wishlist.
  - **Vendor**: Kitchen analytics, menu management with active toggle, ImgBB photo upload, incoming order fulfillment, and Stripe subscription upgrade.
  - **Admin**: User management with block/unblock, menu item moderation, and transaction logs.
- **Dark/Light Mode**: Full theme customization powered by `next-themes`.

## 📦 Tech Stack
- Next.js 16 (App Router)
- React 19 & TypeScript
- Tailwind CSS v4
- Lucide React Icons
- Framer Motion
- Sonner Toasts
- Recharts
- Axios & Canvas-Confetti

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.
